# دليل البلاغ

قبل الفحص: سجل الأثر، وقت البداية، المتأثرين، آخر تغيير، وهل المشكلة متكررة. لا تجمع كلمات المرور أو الملفات الشخصية.

البطء: راجع Task Manager وStorage وقارن المؤشرات مع توقيت المشكلة. لا توقف عملية مجهولة ولا تحذف ملفات المستخدم؛ انخفاض الذاكرة في لحظة واحدة لا يثبت السبب.

الشبكة: تحقق من الكابل أو Wi-Fi وحالة المحول ثم إعداد IPv4. إذا ظهر APIPA وكان DHCP متوقعًا، راجع توصيل الشبكة وVLAN وتوفر DHCP مع مسؤول الشبكة. قد يكون المحول افتراضيًا أو محليًا فقط. تحقق من الحاجة للبوابة وDNS قبل اقتراح تغيير. لا تجدد الإيجار أو تغير الإعدادات دون التفويض وفهم أثر الانقطاع.

الإغلاق: وثق الأدلة، التغيير المعتمد، النتيجة وتأكيد المستخدم. صعد المشكلة مع ملخص مناسب عند الحاجة. الأداة لا تثبت الاتصال الفعلي؛ ذلك يحتاج تحققًا منفصلًا مصرحًا به.
